# 🐉 드래곤 둥지

절차적으로 생성되는 나만의 드래곤을 부화시키고 키우는 **모바일 웹 게임**입니다. 빌드 과정 없이 정적 파일만으로 동작합니다.

## 실행

```bash
python3 -m http.server 8000   # 또는 아무 정적 서버
# http://localhost:8000 접속 (폰에서는 같은 와이파이로 PC IP:8000)
```

GitHub Pages / Vercel / Netlify 등에 그대로 올리면 되고, 폰에서 "홈 화면에 추가"하면 앱처럼 실행됩니다 (PWA manifest 포함).

## 구조

| 파일 | 역할 |
|---|---|
| `js/util.js` | 시드 RNG(mulberry32), 색상/포맷 헬퍼 |
| `js/genome.js` | 속성·등급·성장단계 정의, 유전자 생성/교배(돌연변이), 이름, 능력치 |
| `js/render.js` | **절차적 드래곤 렌더러** (Canvas 2D). 유전자 + 단계 + 시간 → 애니메이션 프레임 |
| `js/state.js` | 게임 규칙과 저장(localStorage): 부화, 먹이, 진화, 골드 생산, 상점, 교배, 모험 보상 |
| `js/battle.js` | 턴제 자동 전투 + 필살기 연출 |
| `js/ui.js` | 화면(둥지/부화장/모험/교배/상점), 도감, 연출 오버레이 |
| `gallery.html` | 생성기 확인용 갤러리 (`?n=12&stage=4&r=3&body=beast&wing=flame` 등) |
| `tools/build.js` | CSS/JS 인라인 단일 파일 `dist/index.html` 생성 |
| `tools/make-icons.js` | 렌더러로 PWA 아이콘 생성 (Playwright 필요) |

## 드래곤 생성 방식

이미지 에셋 없이 유전자로부터 매번 그립니다. 같은 시드 → 같은 드래곤.

- **몸형** 와이번 / 비스트 / 드레이크 / 서펜트 — 척추 곡선(Catmull-Rom) 위에 두께를 입힌 튜브로 몸·목·꼬리·다리를 구성
- **부위 조합** 날개(박쥐/깃털/수정/화염), 뿔(5종 × 재질 5종), 갈기·지느러미 귀·프릴, 등 장식, 꼬리 끝, 무늬, 눈
- **등급 연출** 레어↑ 금팔찌, 에픽↑ 보석 목걸이·이마 보석·리본 오라, 레전드↑ 금빛 고리, 신화 빛줄기
- **성장 단계** 해치링 → 유년기 → 성체 → 고룡: 머리/눈 비율, 날개·뿔 크기, 오라가 단계에 따라 변함
- **교배** 부모 형질을 섞고 12% 확률로 돌연변이, 등급 상승 가능
